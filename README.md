# GTA V Takeover

**Minecraft** × GTA V · visual · idea by the team

Bring GTA V into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Minecraft into Los Santos: wanted stars, police cars, WASTED screens and a boss fight. Villagers have it rough.

## Install

Install Fabric for Minecraft 26.3, then put the mod jar and Fabric API in your mods folder. Start a new survival world: Los Santos is built at spawn, you get a pistol, and the first job starts by itself.
